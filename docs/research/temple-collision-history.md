# Temple collision history selection

CheckBarr4:4e8a copies the working physical row to A5-357c, then calls
**4:5152** at4:4e90. This block recovers that helper and its real20-byte
copy/fill services19:2f72/2ff0. The catalog's decoded InitColDetBufs marker
at4:50da is not used as this entry: that nearby routine has a distinct
head/ceiling body. A name/decoded marker is not proof of a call boundary.

The helper selects one prior pair of ten-word tags/masks. An equal row or
row difference3 selects the current pair; previous=current+1/current-2
selects the upper pair; all other cases select the lower pair. Comparisons
extend signed rows to32 bits before adding, without16-bit wrap. These are
raw physical-row relationships, not a full recovered camera transition.

Only the lower selection can adjust a mask before copying. For a supporting
column0..9 and nonzero horizontal velocity, movement in the facing direction
retains only0xf0; reverse movement retains only0x0f. Other bits are discarded,
not preserved as extra flags. Zero velocity and offscreen columns leave it.
The modified lower mask is also the source copied to the history buffer.

After both history copies, all three source **tag** arrays become0xffff.
The source mask arrays are not cleared (apart from that single lower-mask
edit). The helper itself does not update the previous-row global: its caller
does so later at4:4e94. Actor, saved actor and other metadata stay unchanged.
